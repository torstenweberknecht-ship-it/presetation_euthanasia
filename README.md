# Vortrag: Sterbehilfe

Platzhalterversion einer Präsentationsseite zum Thema Sterbehilfe.

## Inhalt

- `index.html` – Seitenstruktur mit Abschnitten (Einleitung, Rechtslage, Argumente, Fazit, Quellen)
- `css/style.css` – Styling
- `js/main.js` – aktiver Navigationspunkt beim Scrollen

Alle Texte sind als `[Platzhalter]` markiert und müssen noch mit echten
Inhalten befüllt werden.

## Lokal ansehen

Einfach `index.html` im Browser öffnen oder einen kleinen Webserver starten:

```bash
python3 -m http.server 8080
```

## Deployment

Da die Seite statisch ist, kann sie direkt über GitHub Pages ausgeliefert
werden (Settings → Pages → Branch: `main`).
